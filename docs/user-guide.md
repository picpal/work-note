## 1. 시작하기

### 가입 신청

1. 브라우저로 사내 WorkNote 주소에 접속하면 로그인 화면이 나옵니다.
2. **가입 신청**을 눌러 사번·이름·이메일·비밀번호(**10자 이상**)를 입력합니다.
3. 신청 직후에는 로그인할 수 없습니다 — 폐쇄망 보안 정책에 따라 **관리자 승인 후** 계정이 활성화됩니다.
4. 승인되면 기본 역할(방문자, 읽기 전용)로 시작합니다. 편집 권한이 필요하면 관리자에게 요청하세요.

> 이메일은 선택 입력이지만, **2FA 복구 코드 수신**에 사용되므로 등록해 두는 것을 권장합니다.

### 로그인

사번과 비밀번호를 입력합니다. 2FA(TOTP)를 등록한 계정이면 인증 앱의 **6자리 코드**를 입력하는 화면이 한 단계 더 나옵니다. 30분 동안 활동이 없으면 세션이 만료되어 다시 로그인해야 합니다.

## 2. 화면 구성

- **왼쪽 사이드바** — 폴더/노트 트리. 우클릭으로 생성·이동·이름 변경·삭제, 드래그로 이동. `Ctrl/⌘+\`로 접기/펴기
- **가운데 에디터** — 제목·태그·본문. 노트를 열어야 상단 툴바가 활성화됩니다
- **상단 툴바** — 서식 버튼과 내보내기·저장 버튼
- **우상단** — 내 계정(프로필), 테마 전환(라이트/다크)
- **사이드바 하단** — 휴지통, 설정, (관리자에게만) 관리자 콘솔 이동 버튼

## 3. 노트 작성

본문은 마크다운으로 작성하며 **라이브 프리뷰** 방식입니다. `**굵게**` 같은 마크다운 기호는 커서가 그 줄에 있을 때만 보이고, 다른 줄로 이동하면 서식이 적용된 결과만 보입니다.

### 툴바 버튼

| 그룹 | 버튼 | 동작 |
| --- | --- | --- |
| 제목 | H1 ~ H4 | 제목 수준 삽입 |
| 서식 | 굵게 · 기울임 · 취소선 | 선택 텍스트 감싸기 |
| 블록 | 인용 · 목록 · 체크리스트 · 표 | 블록 서식 삽입 |
| 삽입 | 링크 · 이미지 · 파일 첨부 · 코드 블록 | 링크/파일/코드 삽입 |
| 다이어그램 | Mermaid · 시퀀스 | 다이어그램 템플릿 삽입 |

### 체크리스트

`- [ ] 항목`으로 만들고, 렌더된 체크박스를 **클릭해서 바로 토글**할 수 있습니다.

### 코드 블록과 다이어그램

- 코드 블록은 ` ```java `처럼 언어를 지정하면 하이라이트됩니다.
- ` ```mermaid ` 블록은 커서가 벗어나면 플로차트/시퀀스 다이어그램으로 렌더됩니다. 툴바의 다이어그램 버튼이 시작 템플릿을 넣어 줍니다.

## 4. 표 편집

GFM 마크다운 표는 커서가 표 밖에 있을 때 **인라인 표 편집기**로 바뀝니다. 마크다운 원문을 몰라도 표를 다룰 수 있습니다.

- **셀 편집**: 셀을 클릭해 바로 입력
- **범위 선택**: 드래그 또는 `Shift+방향키` — 선택 영역 복사(`Ctrl/⌘+C`)·붙여넣기·`Delete`로 비우기, `Esc`로 해제
- **행/열 추가·삭제**: 행 번호·열 머리글의 핸들 메뉴에서 실행
- **정렬**: 열 메뉴에서 왼쪽/가운데/오른쪽 정렬 지정

편집을 마치고 표 밖을 클릭하면 자동으로 마크다운으로 저장됩니다.

> 셀 병합, 열 너비 지정은 GFM 표준에 없어 지원하지 않습니다.

## 5. 파일 첨부

세 가지 방법 모두 동일하게 동작합니다.

1. 파일을 노트 위로 **드래그&드롭**
2. 클립보드의 파일/이미지를 **붙여넣기**
3. 툴바의 **📎 파일 첨부** 버튼

- **이미지**(png·jpg·jpeg·gif·webp)는 본문에 `![이름](주소)`로 삽입되어 인라인 미리보기됩니다.
- 그 외 파일은 제목 아래 **첨부 바**에 등록되며, 파일명을 클릭하면 다운로드됩니다.
- 허용 확장자와 파일당 용량 제한은 관리자가 정합니다(기본 25MB). 정책에 어긋나면 업로드가 거부되며 사유가 표시됩니다.
- 첨부는 노트에 종속됩니다 — 노트를 읽을 수 있는 사람만 내려받을 수 있고, 노트가 영구 삭제되면 함께 삭제됩니다.

## 6. 위키링크와 백링크

- 본문에 `[[`를 입력하면 노트 자동완성이 열립니다. `[[노트|표시 이름]]` 형태로 라벨을 바꿀 수 있습니다.
- 링크를 클릭하면 해당 노트로 이동합니다.
- 에디터 아래 **백링크 패널**에 이 노트를 참조하는 노트 목록이 표시됩니다.
- 다른 노트가 참조 중인 노트를 삭제하려 하면 **경고 대화상자**가 먼저 뜹니다.

## 7. 검색

`Ctrl/⌘+K`로 검색창을 엽니다. 제목과 본문을 함께 검색하며 제목 일치가 우선 정렬됩니다. 방향키로 이동, `Enter`로 열기, `Esc`로 닫기.

## 8. 폴더 정리와 이동

- **생성**: 폴더 우클릭 → 새 노트/새 폴더. (server 모드에서 최상위 폴더 생성은 관리자만 가능합니다)
- **이름 변경**: 우클릭 → 이름 변경. 이름은 라벨일 뿐이라 권한에 영향을 주지 않습니다.
- **이동**: 우클릭 → 이동(폴더 선택 모달) 또는 트리에서 드래그&드롭.

### 이동 시 노출 변경 경고

폴더/노트를 옮기면 위치의 권한 상속이 바뀌어 **볼 수 있는 사람이 달라질 수 있습니다**. 이동 전에 서버가 노출 변화를 계산해서, 새로 보게 되는 사람·못 보게 되는 사람이 생기면 경고 모달을 띄웁니다(공개 노출·다른 팀 스페이스로의 이동은 강한 경고). 내용을 확인하고 진행 여부를 결정하세요.

## 9. 휴지통

- 삭제한 노트/폴더는 휴지통(사이드바 하단 휴지통 아이콘)으로 이동합니다.
- **복구**는 삭제한 본인(또는 관리자)이 할 수 있습니다.
- 휴지통 항목은 **30일 후 자동으로 영구 삭제**됩니다(운영 설정에 따라 다를 수 있음).
- 즉시 **영구 삭제**는 관리자만 실행할 수 있습니다.

## 10. 공유 링크

권한이 없는 동료에게도 노트 하나를 읽기 전용으로 보여줄 수 있습니다. 공유 링크는 권한 체계(deny 포함)를 넘는 **유일한 read 예외**이며, 생성·열람·취소가 모두 감사 기록됩니다.

### 만들기

노트 우클릭 → **공유 링크**:

- **만료일**: 기본 7일, 1~365일
- **최대 열람 수**: 비우면 무제한
- **대상 지정**: 특정 사번만 열람 가능하게 제한(비우면 로그인한 전 직원)

생성하면 링크가 자동으로 클립보드에 복사됩니다.

### 받은 사람은

링크를 열면 사이드바 없는 읽기 전용 화면으로 노트 본문과 첨부를 볼 수 있습니다. **WorkNote 로그인은 필요합니다** — 공유 링크는 권한(deny)의 예외이지 로그인의 예외가 아닙니다. 만료·취소·열람 수 초과된 링크는 "열 수 없는 링크"로 표시됩니다.

### 취소

같은 메뉴에서 활성 링크 목록을 보고 **취소**할 수 있습니다. 취소 즉시 링크가 무효화됩니다.

## 11. 저장과 동기화

- 제목·본문·태그는 입력을 멈추면 **자동 저장**됩니다(약 1분 주기 전송). 우하단 버튼이 저장 상태를 표시합니다.
- 지금 바로 저장하려면 `Ctrl/⌘+S` 또는 저장 버튼을 누르세요.
- 세션 만료(401)나 서버 장애로 전송이 실패해도 편집 내용은 브라우저에 보존됩니다 — 다시 로그인하면 미전송분이 자동으로 재전송됩니다.
- 서버에 연결할 수 없으면 차단 화면이 뜹니다. 서버 복구 후 **다시 시도**를 누르세요.

## 12. 내보내기

노트 우클릭 또는 툴바의 내보내기 버튼:

- **PDF로 내보내기** — 인쇄 대화상자에서 "PDF로 저장" 선택
- **Markdown(.md)으로 내보내기** — 원문 파일 다운로드
- **클립보드에 복사** — 마크다운 원문 복사

## 13. Redmine 이슈 가져오기

관리자가 Redmine 연동을 켠 경우에만 보입니다.

1. **최초 1회**: 프로필 → Redmine 탭에서 본인의 Redmine API 키를 등록합니다(등록 시 유효성이 즉시 검증되고, 서버에 암호화 보관됩니다).
2. 노트를 열고 툴바의 **Redmine 버튼**으로 패널을 엽니다.
3. 키워드 검색(+ "내 이슈" 필터) → 이슈 선택 → 요약 또는 전체 미리보기 확인
4. 삽입 버튼 선택: **메타 삽입**(이슈 정보 표) / **본문 삽입** / **댓글 삽입** / **전체 삽입** — 커서 위치에 마크다운으로 들어갑니다.

## 14. 프로필과 보안 (2FA)

우상단 계정 버튼 → 프로필:

- **정보**: 이름·이메일 수정 (사번은 변경 불가)
- **비밀번호 변경**: 현재 비밀번호 확인 후 새 비밀번호(10자 이상) 설정. 변경하면 **다른 기기의 세션은 모두 로그아웃**됩니다.
- **보안(2FA)**: 아래 참고

### 2FA(TOTP) 등록

폐쇄망에서도 동작하는 시간 기반 일회용 비밀번호(TOTP)입니다. 인증 앱(Google Authenticator 등)만 있으면 되고 외부 통신이 필요 없습니다.

1. 프로필에 **이메일이 등록되어 있는지** 확인(복구 코드 수신용)
2. 보안 탭 → 등록 시작 → 표시된 **QR 코드**를 인증 앱으로 스캔(또는 시드 문자열 수동 입력)
3. 앱에 표시된 6자리 코드를 입력해 등록을 확정

이후 로그인할 때마다 비밀번호 다음 단계로 6자리 코드를 입력합니다.

> **관리자 계정은 2FA가 사실상 필수**입니다. 첫 로그인 후 유예 기간(기본 7일)이 지나면 등록 전까지 다른 기능이 차단됩니다. 일반 사용자는 선택(opt-in)입니다.

### 기기를 분실했다면 (복구)

1. 로그인 화면의 2FA 단계에서 **복구 코드로 로그인** 선택
2. 사번 입력 → 등록된 이메일로 **8자리 복구 코드**가 발송됩니다(10분 유효)
3. 코드를 입력하면 로그인되며 기존 2FA 등록은 해제됩니다 — 보안 탭에서 **다시 등록**하세요.

이메일이 등록돼 있지 않거나 메일이 오지 않으면 관리자에게 2FA 초기화를 요청하세요.

## 15. 화면 설정

사이드바 하단 설정 버튼: 라이트/다크 테마, 행 밀도(보통/좁게/넓게), 본문 글자 크기, 사이드바 너비, 정렬 가이드, 아이콘 표시 여부. 설정은 브라우저에 저장됩니다.
